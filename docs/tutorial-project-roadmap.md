## 二、推荐总路线（核心产出）

> 依赖关系决定顺序：语言地基 → 并发 → 网络 → 综合项目 → 深化/进阶。
> 恋恋管"系统理论"，施磊管"落地成简历项目"，侯捷管"为什么"。

### 阶段1｜语言地基（侯捷，约 2.5 周）
1. **侯捷《STL 源码剖析》视频 + 同名书**：从第 1 集起就同步看书（视频即书的逐章讲解）。重点章：空间配置器(第2章)、容器、traits。算法章查文档即可，不逐集耗。
2. **侯捷《C++ 内存管理机制》**：malloc/new/allocator，直接给施磊内存池打底。
   - 可选加项：施磊《内存池》(23集)，补内存短板很值。

### 阶段2｜并发（约 7 周）
3. **恋恋风辰《C++ 并发编程》30集**（不跳）：锁、条件变量、原子、内存模型、无锁队列、线程池——系统补并发理论。
4. **施磊《手写线程池》34集**：理论落地成简历项目，吃透死锁分析与 Any/packaged_task。

### 阶段3｜网络（约 5 周）
5. **恋恋风辰《asio 网络编程》29集**：同步/异步、粘包、protobuf 序列化、多线程模型、协程。
6. **施磊《数据库连接池》9集**（可选项，1 周）：为项目实战的 MySQL 连接练手。

### 阶段4｜综合大项目（约 2.5 个月）
7. **恋恋风辰《项目实战》69集**：主打简历项目。第一季(1-38)覆盖 Qt+asio+MySQL+Redis+grpc；第二季(39-67)的分布式锁/断点续传/webrtc 按需选看。

### 阶段5｜深化原理（施磊，约 5 周）
8. **施磊《手写 Muduo》54集**：拆 Reactor/epoll，验证前面理解。
9. 时间允许再上《集群聊天》/《RPC》（恋恋项目为主项目，施磊聊天/RPC 只服务端岗需要时再碰）。

### 阶段6｜进阶挑战（选做，sylar）
10. **sylar 框架**：协程 → IO 协程调度器+epoll+定时器（核心）→ 线程池/日志/配置 → Socket/ByteArray/HTTP → 连接池/RPC/WebSocket。阶段2→3 是门槛，卡住先回头补恋恋并发/asio。

### 对比要点
- 施磊：传统服务端 + 面试向（muduo/RPC/epoll）
- 恋恋风辰：全栈工程向（Qt 客户端 + asio + 分布式），更贴近真实业务系统
- 两条线不冲突：先用恋恋补基础，最后用施磊 Muduo 手写「验货」

## 三、STL 要学到什么程度

- **层次1 会用（应已具备）**：容器选型、迭代器、auto/范围for、常用算法、复杂度认知
- **层次2 懂原理（重点补）**：
  - 各容器底层结构（vector 连续数组、list 双向链表、deque 分段连续、map 红黑树、unordered_map 哈希）
  - 迭代器失效规则、vector 扩容均摊 O(1)、内存碎片
  - allocator 两级配置（128 字节以下走内存池）
  - 模板/仿函数/bind/lambda
- **层次3 背源码（不需要）**：能讲原理即可，细节画图当场答
- **合格判断（4 问）**：
  1. map 底层为什么是红黑树？(有序+查找均衡)
  2. vector vs list 何时用谁？
  3. push_back 后迭代器为何可能失效？
  4. 为什么要内存池？(小对象分配开销/碎片)

## 四、书籍与视频如何结合

- **原则**：视频当主线进度，书当"查漏字典"，每章用代码验证。别试图把书从头读到尾。
- **节奏模板**：看视频对应集(理解) → 翻书对应章节(补细节) → 自己写/改代码验证 → 笔记
- **配套对照表**：

| 阶段 | 视频 | 配套书 |
|------|------|--------|
| STL/内存 | 侯捷《STL源码剖析》视频 | 侯捷《STL源码剖析》书（逐章对照） |
| 并发 | 恋恋《并发编程》 | 《C++ 并发编程实战》第 2 版 |
| 网络 | 恋恋《asio》 | 《Boost.Asio C++ 网络编程》或张远龙《C++ 服务器开发精髓》 |
| 线程池/Muduo | 施磊 | 陈硕《Linux 多线程服务端编程》（Muduo 作者，核心书） |
| 通用查漏 | 任意 | 《Effective Modern C++》每天翻一条 |

- **书的三类用法**：精读（侯捷 STL、陈硕）／查漏（并发实战、Effective）／备查（C++ Primer）
- **顺序**：先视频懂 70%，再书补 30%，最后必须亲手跑代码

## 五、STL 源码怎么获取与读

1. **本地优先**：VS 里对 `std::vector` 按 F12/转到定义，直接读 MSVC STL（安装目录 `VC\Tools\MSVC\<版本>\include`）
2. **侯捷书的 SGI STL**：GitHub 搜 "SGI STL"（书附录也印了核心源码）
3. **在线开源实现**：GCC libstdc++（github.com/gcc-mirror/gcc → libstdc++-v3/include/bits）；MSVC STL（github.com/microsoft/STL）
4. **注意**：书讲的老 SGI STL 与现代实现命名有差异，**以本地 IDE 能跳转的源码为准**，书上记概念与思路

## 七、关键决策与权衡

- **只做一套聊天项目**：恋恋《项目实战》为主项目，施磊《集群聊天》不做重复劳动，避免时间浪费
- **施磊线程池/内存池保留**：因为它们是"能写进简历 + 能讲清原理"的最小闭环，性价比高
- **Muduo 放项目后而非前**：先黑盒使用（聊天项目），再拆盒（手写 Muduo），理解递进更顺
- **STL 学 2 层不学 3 层**：原理层补"基础不牢"的病根，源码背诵层 ROI 低，不投入
